## 🔥 Firebase Integration

The Firebase configuration is ready at `app/lib/firebase.ts`:

```typescript
import { initializeApp, getApps } from "firebase/app";
import { getFirestore } from "firebase/firestore";
import { getAuth } from "firebase/auth";
import { getStorage } from "firebase/storage";
```

### Setup Steps:
1. Create Firebase project at [console.firebase.google.com](https://console.firebase.google.com)
2. Copy config values to `.env.local`
3. Enable Authentication (Email/Password + Google)
4. Create Firestore database with collections:
   - `leads` — Store form submissions
   - `projects` — Manage portfolio items
   - `blog` — Blog posts
   - `testimonials` — Client reviews
5. Enable Storage for image uploads

## 🚀 Deployment Instructions

### Local Development
```bash
cd mythos
npm install
npm run dev
# Open http://localhost:3000
```

### Production Build
```bash
npm run build
npm start
```

### Vercel Deployment
```bash
# Install Vercel CLI
npm i -g vercel

# Deploy
vercel --prod
```

Or connect your GitHub repo to Vercel for auto-deployments.

## ⚙️ Environment Variables

Create `.env.local` from `.env.example`:

```
NEXT_PUBLIC_FIREBASE_API_KEY=your_api_key
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=your_project.firebaseapp.com
NEXT_PUBLIC_FIREBASE_PROJECT_ID=your_project_id
NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=your_project.appspot.com
NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
NEXT_PUBLIC_FIREBASE_APP_ID=your_app_id
NEXT_PUBLIC_FIREBASE_MEASUREMENT_ID=your_measurement_id
ADMIN_EMAIL=admin@mythos.dev
ADMIN_PASSWORD=your_secure_password
NEXT_PUBLIC_APP_URL=https://mythos.vercel.app
```
